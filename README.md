# 🎯 Hızlı Tetik — Aim Trainer

FPS oyuncularının reflekslerini, tıklama doğruluğunu (accuracy) ve hedef takip becerisini geliştirmek için tarayıcıda oynanan, saf HTML/CSS/JavaScript ile yazılmış 30 saniyelik bir nişan antrenman oyunu. Skorlar, küresel bir liderlik tablosunda (leaderboard) gerçek zamanlı olarak yarışır.

**🔗 Canlı demo:** https://prismatic-daffodil-15c65c.netlify.app/

---

## 🚀 Özellikler

- **Farklı hedef türleri:** sabit, hareketli, küçülen ve "erratic" (CS tarzı A-D strafe yapan, ani duran/koşan) hedefler.
- **Puanlama:** normal isabet +2, headshot (merkeze yakın vuruş) +3, 10 seri (combo) sonrası puanlar 2 katına çıkar; iska −1 puan.
- **Anti-cheat:** skor istemciden doğrudan veritabanına yazılmaz. `bright-processor` adlı bir Supabase Edge Function, gönderilen skoru; oyun süresi, tıklama/isabet oranı, combo ve olası skor aralığı gibi kriterlere göre sunucu tarafında doğrular ve öyle kaydeder.
- **Kişiselleştirme:** 3 farklı nişangah (crosshair) seçeneği ve ses seviyesi kontrolü.
- **Canlı liderlik tablosu:** Supabase (PostgreSQL) üzerinden anlık okunur.

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, CSS3, saf JavaScript (ES6+, `requestAnimationFrame`)
- **Backend:** [Supabase](https://supabase.com) — PostgreSQL + Edge Functions (Deno)
- **Hosting:** Netlify

## 📁 Proje Yapısı

```
index.html                              Oyun sayfası
style.css                               Görünüm
script.js                               Oyun mantığı + Supabase istemcisi
*.mp3                                   Vuruş/iska/kazanma/kaybetme sesleri
supabase/functions/bright-processor/    Skor doğrulama edge function'ının kaynak kodu
```

## 🔧 Kendi kopyanı çalıştırmak istersen

1. Repoyu klonla: `git clone https://github.com/Emirhankrcbn/aim-trainer-web.git`
2. Kendi Supabase projeni oluştur, aşağıdaki tabloyu ekle:
   ```sql
   CREATE TABLE public.leaderboard (
       id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       username text NOT NULL,
       score integer NOT NULL,
       created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
   );
   ```
3. `supabase/functions/bright-processor/index.ts` içeriğini kendi projende bir Edge Function olarak deploy et (fonksiyon adını `script.js`'te `fetch(...)` satırındaki isimle eşleştir).
4. `script.js` dosyasının en üstündeki `SUPABASE_URL` ve `SUPABASE_ANON_KEY` değerlerini kendi projenin bilgileriyle değiştir.
5. `index.html` dosyasını tarayıcıda aç — herhangi bir sunucuya ihtiyaç yok.
